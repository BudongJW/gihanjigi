# Gihanjigi（기한지기）

[English](README.md) | 简体中文

Gihanjigi 是一个网页原型，面向在韩国刚刚遭遇诈骗、蒙受资金损失的人。它整理出现在应该做的事、适用的法定期限，以及要交给银行和警方的证据。界面为韩语，程序和期限依据韩国法律。

> Gihanjigi 不提供法律意见。它根据用户选择的条件展示一般程序，并注明每一步依据的条文；仅凭条文无法确定的日期不做推测，而是标记为“需要确认”。这些规则尚未经过律师审阅。

## 功能

| 页面 | 作用 |
|---|---|
| 诈骗类型 | 通过几个问题（为什么汇款、如何汇款、对方是否为亲属）把案件分为电信诈骗、交易诈骗或尚未支持的类型，并给出判断所依据的条文。可以载入两个示例案件 |
| 现在要做的事 | 按受骗后应先后处理的顺序列出该类型的步骤，有期限的步骤附上计算出的截止日期 |
| 期限 | 输入通知书上的日期即可计算法定期限。每个期限都可以展开查看计算过程、备注和条文要旨，剩余期限可以下载为日历文件（.ics） |
| 案件记录 | 读取 KakaoTalk 聊天导出文件（手机、PC 和 Mac 格式）和银行交易明细 CSV，生成按时间排列的记录。出现金额或账号的行会标记出来，由用户确认或修改。整个案件可以保存为文件并重新载入 |
| 进展 | 根据输入的日期显示银行退款程序和刑事侦查所处的阶段 |
| 证据清单 | 只用已确认的记录分别生成交给银行和交给警方的清单，可以打印或复制 |

每条期限规则都注明依据的条文，并链接到韩国国家法令信息中心。2026-10-09 已将所引用的条文与官方原文核对：现行版本；已废止的《检察厅法》则核对其废止前的最后版本。

## 隐私

案件记录只保存在用户设备浏览器的 localStorage 中，不发送到任何服务器，也没有接入分析工具。页面的内容安全策略（`connect-src 'none'`、`form-action 'none'`）让浏览器拦截所有对外请求。示例数据均为虚构。

## 运行

请使用 Node 24.10.0。界面和规则引擎没有任何依赖。

    npm start                 # http://127.0.0.1:4310/
    # http://127.0.0.1:4310/?today=2026-10-09   固定基准日期

## 测试

    npm ci
    npm test                  # 69 项引擎测试（node:test）
    npm run check:browser     # 在 320px、390px 和 1280px 下检查流程并运行 axe
    npm run verify            # 两者都运行

浏览器检查使用 `playwright-core` 和 `axe-core`，不会另行下载浏览器。请通过环境变量 `CHROMIUM` 传入 Chromium 或 Chrome 的路径。GitHub Actions 使用运行器上已安装的 Google Chrome。

## 部署

`src/` 原样上传到 Cloudflare Pages，安全响应头由 `src/_headers` 添加。只有在 GitHub Actions 中于 `main` 分支手动运行 `deploy` 工作流时才会部署。首次设置和所需的密钥见 [`docs/배포.md`](docs/배포.md)（韩语）。

## 目录结构

    src/engine/   规则引擎。可在浏览器和 Node 中原样运行。
      holidays.mjs   2026 年和 2027 年的公休日（推算的农历日期会标注）以及银行休息日
      dates.mjs      期间计算（不算首日、按月计算、月末顺延、营业日）
      law.mjs        引用条文、要旨、核对状态以及国家法令信息中心链接
      classify.mjs   诈骗类型的问题和规则
      deadlines.mjs  11 条期限规则
      checklist.mjs  按类型列出现在要做的事
      stages.mjs     银行退款和侦查阶段
      evidence.mjs   解析 KakaoTalk 聊天和银行交易明细，生成证据清单
      ics.mjs        日历文件（.ics）
      case.mjs       保存和载入案件
    src/ui/       基于引擎的页面，使用原生 JavaScript
    src/_headers  Cloudflare Pages 的安全响应头
    test/         引擎测试
    scripts/      静态服务器和浏览器检查
    docs/         设计说明和部署指南（韩语）
